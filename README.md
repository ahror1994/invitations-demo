# Пригласительные — клиентская демоверсия

GitHub Pages: https://ahror1994.github.io/invitations-demo/

## Что работает на GitHub Pages
Главный экран, анимации, шесть шагов редактора, готовые оформления, загрузка и кадрирование своего фона, 72 семейства шрифтов, редактирование и перемещение текста, четыре языка, PNG, PDF и ZIP, отправка изображения через системное меню при поддержке браузером.

Проекты и загруженные фоны сохраняются **только в браузере посетителя** (IndexedDB/localStorage). Локальная ссылка на проект не переносит его на другое устройство. Очистка данных браузера удаляет локальные проекты. Сохранение в облаке и защищённая серверная админка не входят в статическое демо. Реальная доставка через мессенджеры зависит от устройства и не подтверждается сайтом.

## Запуск
Node.js 22.12+; `npm ci`, затем `npm run dev`. Сборка: `npm run build`. Публикуемая папка — `docs/`, ветка `main`.

## Перенос на сервер
В `server/` сохранены исходники полной Next.js-версии. Установить зависимости в этой папке, создать собственный `.env`, настроить Prisma и ключ администратора. Рабочие базы, пароли, ключи, личные загрузки и данные клиентов намеренно не включены. Для серверной публикации использовать Next.js, не Vite-демо.

Изображения следа курсора: `public/motion-images/01.webp`–`05.webp`. После замены выполнить сборку и обновить `docs/`.
