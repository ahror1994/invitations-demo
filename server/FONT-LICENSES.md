# Библиотека шрифтов

72 семейств, настоящие начертания Regular 400 и Bold 700.

Источник: официальный google/fonts, commit 6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec.

Каждый файл распространяется с собственной OFL.txt. Шрифты можно использовать в коммерческих приглашениях и встраивать в приложение при соблюдении OFL; шрифты отдельно не продаются. Статические экземпляры получены из вариативных файлов без изменения рисунка.
