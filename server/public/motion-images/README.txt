Картинки следа за курсором на главной.
Заменяйте 01.webp, 02.webp, 03.webp, 04.webp, 05.webp своими изображениями, сохраняя имена.
Рекомендуемый вертикальный формат 2:3, минимум 384 x 576 px.
Как в референсе: 10 карточек, 5 картинок повторяются дважды. Файл 06.webp оставлен как резерв и сейчас не используется.
Настройки и пути: src/components/HomeMotion.tsx. Все картинки загружаются до запуска следа.
Появление 800 мс: scale 0 -> 1.2, blur 20 -> 0. Исчезновение 1200 мс: scale 1.2 -> 0.8, blur 0 -> 20.
